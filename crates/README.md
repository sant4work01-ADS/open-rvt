# Crates de OPEN-RVT

Aquí irán los crates de Rust del proyecto. Todavía está vacío: la primera tarea de
modelado creará `nucleo` (modelo e IFC) y los que hagan falta después (geometría,
persistencia, visor, etc.).

Mientras tanto, la única caja de Rust es `src-tauri/`, que contiene la aplicación de
escritorio: preferencias, registros y el puente con la interfaz.
