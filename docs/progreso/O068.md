## 1. Mover (igual para Copiar)

- `faseMover`: `seleccionar → base → destino`. Sin selección previa, el visor
  alterna elementos (raycast) y ejes (`lineaEjeEn`); Enter, clic derecho o
  «Listo» pasan a punto base. Con selección previa se salta directo a base.
- Punto base/destino usan `puntoDibujo` (extremos, medios, cruces,
  intersecciones y Shift ortogonal), como Muro.
- Vista previa `mover-guia` + `mover-distancia` con la medida en vivo; la
  distancia tecleada + Enter usa `puntoConLongitud`.
- Ejes: se seleccionan y se mueven con `ejes.mover` (la distancia se proyecta
  sobre la normal del eje). Las cotas y burbujas las recalcula el núcleo.
- Esc: destino → base; base → sale; selección → limpia. Al terminar, Mover
  queda activo y conserva la selección.
- Archivos nuevos: `BarraMover.tsx`, `aberturasHerramienta.ts`.

## 2. Ventana y Puerta

- Barra propia (`BarraAbertura.tsx`): Ancho, Alto, Antepecho y Nivel de
  referencia (por omisión el nivel de la vista activa; se recuerdan mientras la
  herramienta siga activa). Puerta 0.90/2.10/0.00, ventana 1.20/1.20/0.90.
- Al pasar sobre un muro hay vista previa (`abertura-previa`) y cotas a ambos
  extremos. El clic centra la abertura; número + Enter mide su borde desde el
  extremo más cercano al cursor.
- Núcleo: `abertura_crear(..., nivel=GlobalId)` convierte
  `z_inferior = Elevation(nivel) + antepecho` a la base del muro; guarda
  `Antepecho` (base del muro), `AntepechoNivel` y `Nivel`. Si queda fuera del
  muro (abajo, arriba o a los lados) falla con aviso y no crea nada.
- Edición (`PropiedadesAbertura.tsx`): Ancho, Alto, Antepecho, Nivel de
  referencia y Distancia al inicio. Cada cambio regenera vano, relleno y muro
  con una sola instantánea (Deshacer funciona). Mover desliza la abertura y
  conserva `Nivel`/`AntepechoNivel` (también al copiar o reflejar).
- `campoEditable.tsx` sale de `PanelPropiedades.tsx` para no hacer crecer el
  archivo; `PanelPropiedades` reexporta `CampoEditable` (pruebas existentes).
