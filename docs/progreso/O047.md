## API final

```ts
inferir(entrada: EntradaInferencia): Inferencia
```

```ts
interface EntradaInferencia {
  rayo: { origen: Vec3; direccion: Vec3 };
  proyectar: (p: Vec3) => { x: number; y: number }; // px de pantalla
  candidatos: {
    vertices?: Vec3[];
    aristas?: { inicio: Vec3; fin: Vec3 }[];
    caras?: { poligono: Vec3[]; normal?: Vec3 }[];
  };
  puntoPrevio?: Vec3;                 // último punto fijado
  planoTrabajo: { punto: Vec3; normal: Vec3 };
  bloqueo?:
    | { tipo: "eje"; eje: "x" | "y" | "z" }
    | { tipo: "arista"; inicio: Vec3; fin: Vec3; referencia?: number };
  tolerancia_px?: number;             // por omisión 10
}

interface Inferencia {
  punto: Vec3 | null;
  tipo:
    | "extremo" | "medio" | "sobre_arista" | "interseccion" | "sobre_cara"
    | "eje_x" | "eje_y" | "eje_z" | "paralelo" | "perpendicular" | "plano"
    | null;
  referencia: number | null; // índice del candidato o del eje (0=X, 1=Y, 2=Z)
  guia?: { inicio: Vec3; fin: Vec3 }; // línea punteada (ejes y paralelas)
}
```

`Vec3` es `{x, y, z}`, compatible estructuralmente con `THREE.Vector3`; el módulo
no importa `three` ni necesita cámara real: todo entra por `rayo` y `proyectar`.

## Decisiones respetadas

- Prioridad: extremo > medio > intersección > sobre arista > eje desde
  `puntoPrevio` > paralelo/perpendicular > sobre cara > plano de trabajo.
  Dentro de la misma prioridad gana la menor distancia en px; una prioridad
  menor solo gana si está más cerca por **más de 3 px**.
- Todas las tolerancias se miden en píxeles con `proyectar` (10 px por omisión;
  las aristas candidatas a paralelo/perpendicular se filtran a 40 px).
- Ejes X/Y/Z desde `puntoPrevio`; `bloqueo` ata el resultado a esa recta aunque
  el cursor esté lejos (incluye bloqueo por dirección de arista).
- Sobre cara: corte rayo-plano + punto dentro del polígono; gana la cara más
  cercana a la cámara.
- Candidatos detrás de la cámara o tapados por una cara más cercana (menor
  profundidad a lo largo del rayo) se descartan.
- Sin candidatos se devuelve el corte con `planoTrabajo` (`tipo: "plano"`); si
  el rayo es paralelo al plano, la inferencia es nula (`punto/tipo/referencia`
  en `null`).
- `bloqueo` con dirección de arista se informa como `"paralelo"` y usa
  `referencia` de la arista.

## Cómo cablearlo en la herramienta de O046

En el handler de puntero de la vista 3D:

1. Construir el rayo con `Raycaster` de three.js (`raycaster.setFromCamera`).
2. Pasar `proyectar` con la cámara real:
   `p.clone().project(camera)` y convertir NDC a px del lienzo.
3. Pasar como candidatos los vértices, aristas y caras de la escena cercana
   (los que ya usa el visor para selección), `puntoPrevio` de la herramienta,
   `planoTrabajo` del nivel activo y `bloqueo` por Shift/flechas.
4. Usar `inferencia.punto` como posición de la herramienta y dibujar
   `inferencia.guia` como línea punteada (color por eje: X rojo, Y verde,
   Z azul). El `tipo` sirve para la etiqueta de estado.

La vista no debe replicar la lógica de prioridad: esa es la única capa
compartida y ya está probada aquí.

## Pruebas

`src/features/modelo/inferencias3d.test.ts` usa una cámara ortográfica y una de
perspectiva sintéticas con su `proyectar`:

- 5 px de un vértice → extremo; 12 px → plano (ya no cuenta).
- El mismo caso con la cámara 10× más lejos → mismo resultado (px).
- Punto medio de (0,0,0)-(4,0,0) → (2,0,0).
- Cruce de (0,0,0)-(10,0,0) con (3,-6,0)-(3,2,0) → (3,0,0).
- Sobre arista: (0,0,0)-(20,0,0) con cursor en (3,0.3) → (3,0,0).
- Eje X desde (1,1,0) → (2,1,0) con guía desde el punto previo.
- Bloqueo Z desde (1,1,0) y rayo lejano → (1,1,-29) (cuenta a mano).
- Bloqueo por dirección de arista → (30,30,0) sobre la recta, con guía.
- Secuencia de cursor (extremo → medio → plano) sin estado pegado.
- Paralelo y perpendicular a una arista a 30°.
- Prioridad: eje a 2 px contra extremo a 6 px (gana eje) y a 4 px (gana extremo).
- Vértice tapado por una cara → no cuenta; candidato detrás de la cámara → no cuenta.
- Sin candidatos → plano; rayo paralelo al plano → nulo.
